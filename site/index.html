Every agent’s skills. One native window.

Click to share across agents

Knack links the skill into each agent you click, so there’s only ever one copy.

.agents

Toggle skills and catch drift

Turn a skill off without deleting it. Knack tells you if two copies of a skill drift apart.

Commands and projects

Knack lists your Claude Code slash commands and the skills in any project folder you add.

Built for the keyboard

⌘F
Search skills
⌘N
New skill
⌘E
Edit Markdown
⌘R
Rescan folders

Built-in updates

Check for updates from the app menu and install them without leaving Knack.

100% local and private

Your skills stay plain Markdown files on your Mac. No account, no cloud, no analytics. Knack only contacts GitHub to check skills you installed from there.

Read and edit in place

Skills render with a beautiful code theme, tables, and working links. Press ⌘E to edit in place.

Know when a skill’s source changes

Knack tells you when a skill you installed with npx skills add changes on GitHub or drifts from what you installed, and updates it in one click.

Create once, symlink everywhere

Knack fills in the form from any SKILL.md you paste, then saves one copy and links it to every agent and project you pick.
