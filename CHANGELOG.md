# Changelog

Notable changes to Knack. Releases are on [GitHub](https://github.com/jondcallahan/knack/releases).

## 0.2.1 — 2026-11-24

### Changed

- Buttons say what a click will do. Buttons that open your browser show an arrow icon, "New skill" uses + everywhere, and anything that opens a dialog or form first ends in "…".
- The Skill menu says **Enable** or **Disable** to match the selected skill, and menu items use title case throughout.

## 0.2.0 — 2026-11-24

### Added

- **GitHub source tracking.** Knack checks skills you installed with `npx skills add` against their GitHub repo on launch and on ⌘R. It tells you when there's a newer version, when you've edited your copy, or when the repo no longer has the skill. Click **Update** to install the latest version.

## 0.1.2 — 2026-11-23

### Added

- DMG installer artwork.

## 0.1.1 — 2026-11-23

### Changed

- Releases are signed with a Developer ID and notarized by Apple.

## 0.1.0 — 2026-11-23

First release: browse, edit, enable or disable, and share agent skills across Claude Code, Codex, Cursor, Gemini, OpenCode, and project folders.
